# Outlines de circuitos

Esta carpeta contiene los 24 trazados distintos que aparecen en el calendario de Assetto F1 2026. Todos los archivos usan líneas vectoriales escalables y la variante vigente de cada circuito.

Fuente general: [F1 Circuits SVG](https://github.com/julesr0y/f1-circuits-svg), creado por ROY Jules (`julesr0y`). Se usa la variante detallada `white-outline`; para Singapur corresponde `marina-bay-4`, el trazado actual de Marina Bay.

Excepciones:

- Sepang fue adaptado desde [Circuit Sepang 1999 Infobox.svg](https://commons.wikimedia.org/wiki/File:Circuit_Sepang_1999_Infobox.svg), obra de AlexJ publicada con dedicación CC0.
- Monza fue redibujado sobre [Autodromo monza.svg](https://commons.wikimedia.org/wiki/File:Autodromo_monza.svg), publicado en dominio público.

Licencia de la colección F1 Circuits SVG: Creative Commons Attribution 4.0 International (CC BY 4.0). El texto completo se conserva en `LICENSE-CC-BY-4.0.txt`.

La colección incluye Albert Park, Shanghai, Suzuka, Bahrain, Jeddah, Miami, Montreal, Mónaco, Barcelona-Catalunya, Red Bull Ring, Silverstone, Spa-Francorchamps, Hungaroring, Zandvoort, Monza, Madring, Baku, Sepang, Marina Bay, Hermanos Rodríguez, Interlagos, Las Vegas, Lusail y Yas Marina.
