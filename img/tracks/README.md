# Outlines de circuitos

Esta carpeta contiene los 23 trazados distintos que aparecen en el calendario de Assetto F1 2026. Se usó la variante detallada `white-outline` correspondiente al trazado 2026 y solamente se renombraron los archivos para que sean fáciles de mantener.

Fuente: [F1 Circuits SVG](https://github.com/julesr0y/f1-circuits-svg), creado por ROY Jules (`julesr0y`).

Licencia: Creative Commons Attribution 4.0 International (CC BY 4.0). El texto completo se conserva en `LICENSE-CC-BY-4.0.txt`.

La colección incluye Albert Park, Shanghai, Suzuka, Bahrain, Jeddah, Miami, Montreal, Mónaco, Barcelona-Catalunya, Red Bull Ring, Silverstone, Spa-Francorchamps, Hungaroring, Zandvoort, Monza, Madring, Baku, Sepang, Hermanos Rodríguez, Interlagos, Las Vegas, Lusail y Yas Marina.
